# 📝 Notes App

A beautiful, full-featured notes application built with Flask. Capture your thoughts, organize them with tags, and pin the important ones.

## ✨ Features

- 👤 User registration and login
- 🔐 Password hashing with bcrypt
- 📝 Create, edit, delete notes
- 🏷️ Tag system (many-to-many relationships)
- 📌 Pin important notes
- 🔍 Search notes by title or content
- 🎨 Modern gradient design with Bootstrap 5
- 📱 Fully responsive
- 🛡️ Custom error pages (404, 500)

## 🛠️ Technologies Used

- **Backend:** Flask (Python)
- **Database:** SQLite with SQLAlchemy (many-to-many relationships)
- **Authentication:** Flask-Bcrypt, Sessions
- **Frontend:** Bootstrap 5, Font Awesome, Inter font, Jinja2
- **Deployment:** Render
- **Version Control:** Git & GitHub
